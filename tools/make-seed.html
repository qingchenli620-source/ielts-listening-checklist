生成词表 SQL

这个页面只在你自己的电脑上运行。它会把语料库 JSON 分成几段 SQL，你再粘贴到 Supabase 的 SQL Editor。页面里一开始没有单词。

生成出来的 SQL 含有全部单词。不要上传到 GitHub，不要发给买家，不要发到群里。只粘贴到你自己的 Supabase。
  1. 在 GitHub 仓库页面点 Code → Download ZIP，解压。
  2. 双击打开解压后的 tools/make-seed.html（不要在 GitHub 网页里打开）。
  3. 选择 corpus_bv1nTNkzjEVn.json。
  4. 先确认已经运行过 supabase/schema.sql。
  5. 下面每一段按顺序点「复制」，到 Supabase → SQL Editor → New query 粘贴，点 Run。看到 Success 再做下一段。
  6. 最后一段是检查。结果应是 videos = 32，items = 5463。
